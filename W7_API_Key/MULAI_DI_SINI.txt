BOOKDATA API - HASIL LENGKAP W7 + BUSINESS MODEL API KEY

1. Jalankan aplikasi dari Proyek_Lengkap. Folder anggota berisi salinan file lengkap per tanggung jawab, bukan empat aplikasi terpisah.
2. Baca panduan MD sesuai urutan: 01_Kenneth, 02_Bryan, 03_Dana, 04_Rafael.
3. Setiap folder anggota memiliki kode/ dengan path asli W7 dan PERUBAHAN.diff untuk membandingkan terhadap starter.
4. PPTX berada di Presentasi/BookData_API_Key_Final.pptx.
5. Di Proyek_Lengkap: npm ci, npm run setup:env, edit .env untuk MySQL.
6. Database baru/reset: npm run db:migrate, kemudian npm start.
   Database W7 yang datanya dipertahankan: backup dan gunakan npm run db:upgrade.
7. Untuk pengujian terpisah: npm run test:prepare kemudian npm test.
8. Import Postman BookData-W8 dan environment bookdata-local untuk demo 18 request.

Tidak disertakan node_modules atau .env yang sudah berisi secret. setup:env membuat secret lokal otomatis. Dokumentasi W7 asli dipertahankan sebagai .txt di Proyek_Lengkap/docs/asli agar terdapat tepat empat panduan .md di paket.
